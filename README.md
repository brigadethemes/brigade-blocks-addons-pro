# Brigade Blocks Addons Pro

The landing page of Brigade Blocks Addons Pro, the add-on for the free [Brigade Blocks Addons](https://wordpress.org/plugins/brigade-blocks-addons/) plugin.

Live: https://brigadethemes.github.io/brigade-blocks-addons-pro/

A static site (no build step): `index.html`, `assets/style.css`, the Urbanist font (SIL Open Font License, see `assets/fonts/OFL.txt`). Publish with GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.

To change where "Get Pro" leads once the CodeCanyon item is live, edit the `#buy` section in `index.html`.
