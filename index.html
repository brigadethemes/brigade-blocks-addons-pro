What’s in Pro

Four Pro modules, switched on or off like the free ones

Each module appears on the same Brigade Blocks settings screen. Switch off what you don’t need: a module that’s off loads nothing.

  • Loop Builder — query any post type, design each item with blocks; grid, list or carousel; Load more and infinite scroll

Popups

  • Modal, slide-in or bar designed with any blocks
  • Opens on load, scroll, exit intent or click
  • Frequency, device and logged-in / logged-out rules

Mega Menu

  • Items that open panels of any blocks — columns, links, images, buttons

  • Built-in mobile menu

Shop Tools (WooCommerce)

  • Wishlist — heart buttons on products and a wishlist page

Pick posts, pages, products or any custom post type — filter by category, tag, custom field or author — and design one item with blocks. Every result uses it.

  • Grid, list or carousel layouts

Popups

Offers and announcements that respect visitors

Build the popup with any blocks — a form, a coupon, a video. Choose when it opens and how often it comes back; Escape, the close button and the backdrop always close it.

  • Modal, slide-in or top / bottom bar
  • Page load, scroll depth, exit intent or click (any link to its anchor)
  • Every visit, once per visit, every few days or once
  • Native dialog: focus stays inside, the page behind is inert

FAQ

Questions

Do I need the free plugin?

Yes. Pro is an add-on to Brigade Blocks Addons from WordPress.org. Install the free plugin first; Pro starts automatically once both are active.

What do I need to run it?

WordPress 6.5 or later and PHP 7.4 or later. Shop Tools also needs WooCommerce.

What happens to my site if my licence ends?

Every Pro block keeps working. You only stop receiving updates and support.

Can I switch off the parts I don’t use?

Yes. Each Pro module and block has its own switch on the Brigade Blocks settings screen. Modules that are off load nothing.

Where is the documentation?

Block guides are on the Brigade Blocks Addons documentation site.

Is it GPL?

Yes. Like WordPress and the free plugin, Pro is licensed under the GPL (version 2 or later).
